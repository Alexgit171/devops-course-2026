# Сравнение Git и SVN

1. В Git ветвление — это просто указатель на коммит, поэтому оно мгновенное и не копирует файлы. В SVN ветка — это копия директории на сервере, что медленно и затратно.

2. Нет, в SVN коммит невозможен без интернета, так как это централизованная система, и все изменения отправляются на сервер. В Git коммиты локальные.

3. SVN может быть предпочтителен в крупных legacy-проектах с жёсткой централизацией, где не нужны распределённые фичи, а также при работе с большими бинарными файлами (хотя Git LFS решает это).
